# 📖 About

**Special Logo Cards** is a front-end motion study built as a small gallery of dimensional cards.

Each card is assembled from layered surfaces. On hover, the top and side panels open and the piece turns from a flat block into a three-sided form. The effect is done entirely in CSS.

The repository is a visual interface experiment: color, depth, hover timing, and layout without a framework or a script file.

> **Tagline:** *A pure CSS gallery of animated 3D cards that open on hover.*

---

# 🚀 Why This Project?

Motion does not always need JavaScript.

This page keeps the idea tight:

- One HTML file
- One stylesheet
- Five cards
- One hover language shared across the set

It is a portfolio piece for interface motion and CSS structure.

---

# ✨ Key Features

- 🎴 Five colored cards in one gallery
- 🧊 Layered surfaces that open on hover
- 🎨 Distinct color for each card
- 🖱️ CSS-only interaction
- ⚡ No JavaScript and no build step
- 🌐 Ready to host on GitHub Pages
